Box Model Lab

Chứng minh content-box, border-box và layout 3 cột.

Phần 1 — Content-box vs Border-box

Hai hộp bên dưới cùng khai báo width: 300px, padding: 20px, border: 5px solid.

Hộp 1: content-box

Width thật = 300 + 40 + 10 = 350px

Hộp 2: border-box

Width thật = 300px

Phần 2 — Layout 3 cột không dùng border-box

Container rộng 1000px. Vì padding cộng thêm vào width nên tổng lớn hơn 1000px.

Trường hợp sai: content-box
Sidebar
width 250 + padding 30 = 280px
Content
width 500 + padding 40 = 540px
Ads
width 250 + padding 30 = 280px

Tổng thực tế = 280 + 540 + 280 = 1100px, nên có thể bị tràn hoặc vỡ layout.

Phần 2 — Layout 3 cột dùng border-box

Với border-box, padding nằm bên trong width. Tổng đúng 1000px.

Trường hợp đúng: border-box
Sidebar
250px
Content
500px
Ads
250px

Tổng = 250 + 500 + 250 = 1000px.
